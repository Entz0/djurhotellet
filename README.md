Projektet är ett hanteringssystem för ett katthotell utvecklat i Java för att administrera incheckade katter och hålla dagliga upprop. Programmet registrerar kattens namn, ras och chipnummer samt förhindrar dubbelregistreringar genom att validera att varje chipnummer är unikt. Lösningen tillämpar objektorienterad programmering och god inkapsling, där katternas information och hotellistan skyddas via privata fält och kontrollerade metoder.
